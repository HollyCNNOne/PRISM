## 1. 对象与问题

> 机制假设：$\mu_z=(1-\Delta)\mu_{z-1}+\Delta\mu_{\text{cand}}$，携带项每片乘 $(1-\Delta)$。

**可证伪推论**：近环内，$\mu$ 的带限相关应随「到最近无金属片的距离 $d$」**单调下降**。
若与 $d$ 无关，则对 $\Delta$ 传递的理解有误。

## 5. 方法

对每条序列跑一次完整双向递归 → 取融合先验 μ 与最终输出 out →
逐片在当前片的 near 环带内算 `corr(HP_σ(·), HP_σ(GT))`，按 $d$ 分箱取均值。

## 8. 状态与已知问题

**结论摘要（3 行，分析见 `RESEARCH_LOG.md` → V2.2-baseline-SSM-3）**

1. **σ=1 随 d 单调下降**：0.134（d=1）→ 0.081（d=2）→ 0.031（d=3-4）→ **每片 ×0.60**，即 $\Delta\approx0.4$。
2. **σ=16 每片 ×0.85**（$\Delta\approx0.15$）→ 传递是**低通**的，且程度可精确量出。
3. **出口损失随 d 增大**：out/μ 在 d=1 是 105%，d=2 是 **46%**，d=3-4 是 **42%**。
