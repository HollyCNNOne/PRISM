# PRISM 数据文档（DATA_LOG）

> **本文档的职责（三份文档分工）**
> - `_scratch/RESEARCH_LOG.md` = **科研日志**：只写分析、推理、判断、对论文的含义

```

   ↓ regen_phys.py         (同一条 L_noisy 上算)
```

- 目录名 `training_data_astra` 是历史命名，**不代表用 ASTRA**；解析线唯一真源 = `analytic_sim/`。
